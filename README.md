Entry for [The Funniest AI Excuse](https://make.fun/c/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0)
on [make.fun](https://make.fun): a program that writes one line — the funniest
excuse an AI agent gives after failing a task, 200 characters at most — to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.

The line:

> I forwarded your task to support. Support is me. I closed the ticket as resolved.

Run it with Node 22.18+:

```sh
node main.ts
```
